🧬 HLA-Verify

Catch fabricated, deleted and legacy HLA allele names in LLM output, typing reports and GL strings. Every name is looked up in a pinned IPD-IMGT/HLA release, never guessed: deterministic, no LLM anywhere.

Free API key for academic research. HLA-Verify is free during early access: 100 calls a day without a key, more with one. University and hospital researchers can apply for a free key.

Have an API key? (optional)

Paste an LLM answer, a typing report or any text. Every allele-shaped token is checked (POST /v1/verify).

Rewrite legacy, renamed and shorthand names to current form, and flag what cannot resolve (POST /v1/normalize). One name per line, or comma-separated; up to 250 without a key.

Status, G/P group, serology, first release, KIR ligands and, for a two-field name, how many full-resolution alleles it stands for (GET /v1/allele/{name}).

Match count with host-versus-graft and graft-versus-host direction (POST /v1/match), plus optional HLA-B leader and KIR-ligand checks (POST /v1/compat). One locus per line, e.g. A*02:01, A*24:02 or A: A*02:01, A*24:02; list one allele for a homozygous locus.

Validate a GL String and rewrite its names to current form (POST /v1/glstring).

MCP: Claude, Cursor or any MCP client

Streamable HTTP. A key is optional and goes in an X-API-Key header.

{"mcpServers": {"hla-verify": {"url": "https://api.hlaverify.com/mcp"}}}

REST

curl -s https://api.hlaverify.com/v1/verify -H 'content-type: application/json' \
  -d '{"text": "A*02:01 and B*57:01:99"}'
# with a key: add  -H 'x-api-key: hlv_...'
